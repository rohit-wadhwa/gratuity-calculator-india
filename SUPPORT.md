# Support for Gratuity Calculator India

Thank you for using the Gratuity Calculator. If you're encountering issues or have questions, here's how to get help.

## Reporting Issues

If something's not working as expected, please let us know by filing an issue on GitHub:

1. **Go to**: [File an Issue](https://github.com/rohit-wadhwa/gratuity-calculator-india/issues/new)
2. **Describe the Issue**: Tell us what's happening, what browser you're using, and include a screenshot if possible. The more details you provide, the faster we can help.

## Why GitHub?

- **Direct Notifications**: We get notified immediately about new issues.
- **Clear Communication**: GitHub allows us to discuss and resolve issues transparently.
- **Community**: Others with the same issue can find solutions in existing threads.

## After You Report

We'll look into your issue as soon as possible. For common problems, check the existing [issues](https://github.com/rohit-wadhwa/gratuity-calculator-india/issues) — there may already be a solution.

## General Feedback

If you have suggestions, feedback, or general questions:

- [Start a Discussion](https://github.com/rohit-wadhwa/gratuity-calculator-india/discussions)

## Important Disclaimer

This calculator is for **illustration purposes only**. For your exact gratuity entitlement, please consult your employer's HR/payroll department. This tool does not provide tax or legal advice.
